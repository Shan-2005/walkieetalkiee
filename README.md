# Robofest 2.0 — Walkie-Talkie Web App

Real-time Push-to-Talk walkie-talkie PWA for event coordination.

## Features
- 10 dedicated event channels with floor control
- Push-to-Talk via on-screen button or hardware volume keys
- Multi-channel Receiver Command Center dashboard
- Mobile-first glassmorphic dark-theme UI

## Deploy
Click "New Web Service" on Render.com, connect this repo, and deploy.
- **Build Command**: `npm install`
- **Start Command**: `npm start`
